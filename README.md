# Java Spring Training Repository

Deze repository bevat trainingsmateriaal gericht op **Java Spring MVC** en **Java Spring REST**. Het doel van deze training is om ontwikkelaars te helpen de basisprincipes, architectuur en toepassingen van het Spring-framework te begrijpen.

## 📘 Onderwerpen in deze training
- **Spring MVC**: Model-View-Controller architectuur voor webapplicaties.
- **Spring REST**: Het bouwen van RESTful API’s met Spring Web.
